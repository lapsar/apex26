Весь чек-лист прогоняется одной командой: `cd tools && npm install` один раз, дальше
`node tools/run-all.js` — ~23 минуты на 4 ядрах (пробники идут разом, каждый в своём
процессе; по одному — 83 мин, замер 09.2026; прежние «около трёх минут» устарели),
код возврата 0 или 1. Для правки окружения (цвет, реклама, трибуны, щиты) по ходу работы
хватает быстрой проверки `--only=pole,print,load,materials,clear,wall,solid,dispose,sit`
(~3 мин); полный прогон перед выдачей сборки — обязательно. Подробности и оговорки
в `tools/README.md`. Каждый пробник проверен на намеренно испорченной копии игры — список
поломок и того, кто их ловит, там же. `index.html` пробники только читают.
