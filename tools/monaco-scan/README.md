# Замер Монако: контур, середина дороги, линия старта (этап 0, v1.16.22)

## Что оказалось доступно (01.10.2026)

* **Контур** — `bacinger/f1-circuits`, `mc-1929.geojson` (159 точек, 3316 м), тот же,
  что вшит в игру с самого начала. Направление обхода = гоночное (телеметрия: 39 шагов
  вперёд, 0 назад).
* **OSM** — отношение 148194 «Circuit de Monaco» (type=circuit, 43 пути: улицы и куски
  raceway, пит-лейн с ролью pit_lane, узел **start-finish 4937755860**). Монако в OSM
  размечен очень подробно: 2971 здание (461 с высотой или этажами), 202 тротуара
  (footway=sidewalk), береговая линия, причалы. Overpass из песочницы НЕДОСТУПЕН —
  данные сняты через API 0.6 `/map` тайлами 0.004° (35 запросов), склейка `osm/all.json.gz`.
* **Спутник** — Google z20/z21 и ESRI z19 качаются (`view.py`; Google — только с User-Agent).
* **openf1** — сессии Гран-при 2025 (гонка 9979, квалификация 9975), положения
  болидов (`openf1/`): круг Норриса для совмещения и стоящая решётка перед стартом.

## Середина дороги: снимок не годится, годится OSM

`halfwidth.py` (порт хунгарорингского) на улицах Монако находит полотно на 3 станциях
из 663 — машины, тени, разметка. Вместо него два независимых источника OSM:

| | что меряет | покрытие |
|---|---|---|
| `osmoff.py` | ось улицы трассы (пути отношения 148194) | весь круг |
| `sidewalk.py` | середина между тротуарами слева и справа | ~36 % круга |

Между собой на 118 общих станциях: корреляция 0.62, медиана разности 0.52 м.
Исходный контур на открытых улицах уже шёл по середине (медиана |отступа| 0.3–0.6 м),
расходился в четырёх местах: **тоннель (до 6.2 м, по оси OSM)**, **набережная у бассейна
(до 3.4 м, оба источника)**, Сент-Девот (1.9 м), площадь Казино (1.3 м).

`recenter.py`: медиана источников (тротуары, разошедшиеся с осью больше чем на 2 м,
отбраковываются — без этого второй проход раздувал остаток до 5 м), сглаживание σ=20 м,
каждая точка сдвигается по нормали. Три прохода → `mc-1929-center.geojson`; остаток
от середины 10 %/90 %: ось −0.5/+0.6 м, тротуары −0.8/+0.5 м (у Хунгароринга после
пересадки ±0.8). **В тоннеле источник один — ось OSM**: снимок под отелем слеп, тротуаров
нет; взята ради согласия с домами OSM, из которых будет строиться мир.

## Линия старта: была на 37 м впереди

| источник | S на исходной ломаной mc-1929 |
|---|---|
| OSM, узел start-finish | 2420.2 |
| снимок z21: клетчатая полоса поперёк Бульвара Альберта I | ≈ 2421.7 |
| openf1: поул (Норрис) на решётке за 1 с до старта 2025 | 2421.7 (остальные 19 — назад через 6–12 м) |
| игра до v1.16.22 (`sfShift` 2460) | **2460.2** |

Поул стоит на самой полосе (±2 м — точность совмещения), то есть настоящая стартовая
черта, если она отдельная, не дальше 3 м впереди. В игре линия одна — она поставлена на
клетчатую полосу: её и видно, по ней и решётка. После пересадки и сглаживания полоса
лежит на сплайне игры на дуге 2416.5 → `sfShift=2416` (ближайшая точка сплайна в 1.3 м).
Совмещение openf1 → контур (`f1fit.py`): масштаб 0.9948 (контур на 0.5 % короче
настоящего, как у всех трасс), ошибка медиана 1.5 м.

## Скрипты

| Файл | Что делает |
|---|---|
| `mc.py` | контур в метрах (`MC_GEOJSON` — другой файл), `at(S)`, `proj(точка)`, `xy/latlon` |
| `osm.py` | склейка OSM; `python3 osm.py` — сводка |
| `osmloop.py` | попытка сцепить пути отношения в кольцо — НЕ сцепляется (пути стыкуются не концами); не нужна |
| `osmoff.py` | отступ оси улицы OSM от контура по станциям |
| `sidewalk.py` | отступ середины между тротуарами |
| `recenter.py` | пересадка контура на середину |
| `halfwidth.py` | поиск полотна по снимку — на Монако не работает (отрицательный результат) |
| `tiles.py`, `view.py` | снимок сверху с наложением контура, OSM, точек; `views/` — ключевые кадры |
| `f1fit.py` | совмещение координат openf1 с контуром |
